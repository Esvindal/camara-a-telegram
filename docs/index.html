Servicio en Python que escucha los eventos de una cámara IP Dahua o Hikvision, toma la foto del momento, la envía por Telegram y la registra en SQLite y CSV. Incluye un simulador para probarlo sin cámara.

Cómo funciona

  1. Escucha. Se suscribe al flujo de eventos de la cámara por HTTP: eventManager.cgi en Dahua o alertStream (ISAPI) en Hikvision, con autenticación Digest.
  2. Fotografía. Ante un evento activo, pide el snapshot JPEG del canal a la misma cámara.
  3. Avisa. Envía la foto por sendPhoto de la API de Telegram con tipo de evento, cámara y hora local (UTC-3). Reintenta con espera creciente y aplica un enfriamiento por tipo para no spamear.
  4. Registra. Guarda cada evento en SQLite y lo exporta a CSV. Sin servidor web: corre como proceso o contenedor.

Arquitectura

Todo el tráfico es saliente: el servicio llama a la cámara y a la API de Telegram; no abre ningún puerto. La cámara se alcanza por la red local o una VPN/túnel, nunca expuesta a Internet.

Conectar una cámara real

  1. Usuario de solo lectura. Creá en la cámara un usuario con permiso mínimo (ver eventos y snapshots). No uses admin.
  2. Bot y chat id. Creá el bot con @BotFather, mandale /start y obtené el chat id con python scripts/obtener_chat_id.py.
  3. Configurar. Copiá .env.example a .env y completá CAMARA_FUENTE=dahua (o hikvision), CAMARA_URL, usuario, clave y los valores de Telegram.
  4. Probar sin enviar. camara-a-telegram run --dry-run muestra lo que enviaría sin llamar a Telegram.
  5. En marcha. camara-a-telegram run o docker compose up -d.
# arranque en 5 minutos con el simulador
python -m venv .venv && .venv\Scripts\activate   # o source .venv/bin/activate
pip install -e .
camara-a-telegram run --fuente simulator --dry-run
